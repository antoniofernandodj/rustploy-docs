O Rustploy guarda o estado da infraestrutura (projetos, serviços, jobs, contas Git e as
configurações) em arquivos YAML. **Baixar a infra** entrega esses arquivos num `.zip`: é uma
cópia fora do servidor e fora do GitHub, boa para guardar e para conferir o que está gravado.

<Aside type="note" title="Isto substituiu o antigo Infra as Code">
  Havia uma aba **Infra as Code** que exportava e importava um manifesto próprio
  (`rustploy.yml` + `rustploy.vars.toml`). Era um formato paralelo ao estado real e foi removido,
  junto com os comandos `ManifestApply`, `ManifestExport`, `ManifestExportAll` e `ManifestImport`.
  Quem os usava por agente ou script precisa migrar para o fluxo abaixo.
</Aside>

## Como baixar

<Aside type="note">Disponível a partir do daemon 0.1.34 (release v0.1.40).</Aside>

**Settings → Sincronização → Baixar a infra → Baixar infra**, no app desktop ou na web UI. O arquivo é
`rustploy-infra.zip`. Um agente usa o comando `InfraDownload`.

## O que vem no zip

A mesma árvore que a [sincronização com o git](/guias/sincronizacao-git/) grava no repositório:

| Arquivo | Conteúdo |
|---|---|
| `MANIFEST.json` | versão do formato |
| `settings.yml` | configurações do daemon |
| `providers.yml` | contas Git conectadas (sem token em claro) |
| `projects/<id>/project.yml` | um projeto, com seus serviços e jobs |

Os segredos vão como `ENC[age:…]`: cifrados com a chave do servidor (e, se configurada, a de
recuperação). **Nada sai em claro.**

<Aside type="caution" title="O download recusa quando há valor em claro">
  Se o estado tem um valor que deveria estar cifrado (veja **A trava** em
  [Sincronização com o git](/guias/sincronizacao-git/#a-trava-nada-em-claro-entra-no-histórico)),
  o download é **recusado**, com a mesma lista do `InfraAudit`: ele não entrega o que o Git não aceitaria.
  Mova os valores para secrets e tente de novo.
</Aside>

## Restaurar

Não há "importar o zip". Restaurar é pôr a árvore num repositório e **sincronizar**: aponte o servidor
novo para o repositório e use a mesma chave de recuperação. O passo a passo está em
[Restaurar num servidor novo](/guias/sincronizacao-git/#restaurar-num-servidor-novo).

## Para copiar só um serviço

Use o [pacote de serviço](/guias/copiar-servico/) (**Exportar serviço** e **Importar**). Os campos do
`service` estão na [referência do formato](/referencia/manifesto/).
