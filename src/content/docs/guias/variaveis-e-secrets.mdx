## Duas camadas

| Camada | Onde editar | Vale para |
|---|---|---|
| **Projeto** | projeto → aba **Variáveis** | todos os serviços do projeto |
| **Serviço** | serviço → aba **Environment** | só aquele serviço |

Se a mesma chave existe nas duas, **a do serviço vence**.

Os dois lugares têm um **editor `.env`**: uma linha `CHAVE=valor` por variável,
com suporte a comentários (`# …`) que são preservados.

<Aside type="note">
  As variáveis são entregues ao container **quando ele é criado**. Depois de
  mudar uma variável, faça um novo **Deploy** para ela valer.
</Aside>

## Secrets

Valores sensíveis (senhas, chaves de API, tokens) vão para um **secret**, que é
cifrado antes de ir para o banco.

### Criar

No projeto, aba **Secrets**: informe o **nome** (`API_KEY`) e o **valor**. Salvar
cifra o valor na hora. Ele **não volta a ser exibido**: a lista mostra só o nome.
Para trocar o valor, salve outro secret com o **mesmo nome**.

### Usar numa variável

Uma variável pode referenciar um secret em vez de conter o valor. De qualquer
destes jeitos:

- nas **variáveis do projeto**, ligue **"usar secret"** ao adicionar a variável e clique no nome do secret;
- na aba **Environment** do serviço, ponha `<secret:API_KEY>` como valor;
- no editor `.env`, escreva `API_KEY=<secret:API_KEY>`.

Depois de salvar, a variável aparece como `secret:API_KEY`: uma referência, não
o valor. O Rustploy decifra **em memória** só na hora de criar o container.

### Remover

O `✕` na linha do secret apaga o valor, sem como recuperar. As variáveis que o
referenciam passam a receber **texto vazio** no próximo deploy; o deploy não
falha, o container só sobe sem o valor.

### Secret para clonar repositório privado

O mesmo mecanismo serve para o token de clone. Veja [Git](/guias/git/).

## O que é e o que não é protegido

| Protegido | Não protegido |
|---|---|
| O valor nunca vai em texto plano para o banco | Quem tem o token da API **lê os valores decifrados** (a API devolve as variáveis resolvidas) |
| Listar secrets devolve só os nomes | Quem entra no container vê as variáveis de ambiente |
| URLs de clone aparecem como `***` nos logs | Uma exportação de manifesto com valores `Plain` leva os valores comuns |

<Aside type="danger" title="Faça backup da chave mestra">
  Os secrets são cifrados com a chave em `/etc/rustploy/master.key`. Sem ela, os
  valores gravados são irrecuperáveis. Guarde uma cópia em lugar seguro.
</Aside>

## Backup automático

O daemon grava, por padrão a cada 60 s, snapshots das variáveis de projetos e
serviços em `<db_path>/env_backups/`, o que protege contra uma edição
equivocada.
