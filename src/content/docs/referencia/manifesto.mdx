O **pacote de serviço** (veja [Copiar um serviço entre servidores](/guias/copiar-servico/)) leva um
`service` em YAML. Esta página é a **referência dos campos** desse `service`, gerada do código do
daemon e do `rustploy-shared`.

<Aside type="note" title="O manifesto do servidor inteiro não existe mais">
  O antigo manifesto de Infra as Code (`rustploy.yml` + `rustploy.vars.toml`, com `projects:`)
  foi removido. Para uma cópia da infra inteira, use [Baixar a infra](/guias/infra-as-code/); para
  restaurar, a [sincronização com o git](/guias/sincronizacao-git/).
</Aside>

## Campos

**Obrigatório** diz se o campo precisa existir para o arquivo ser aceito.

### `service`

| Campo | Tipo | Obrigatório | Padrão | |
|---|---|---|---|---|
| `name` | texto | sim | — | Obrigatório. **Chave de casamento** dentro do projeto. |
| `source` | objeto `source` | sim | — | Obrigatório. De onde vem o serviço (veja `source`). |
| `port` | inteiro | não | `0` | Porta do app **dentro** do container. Omitida, vale `0` (sem erro, mas o serviço não terá porta útil). |
| `host_port` | inteiro | não | ausente | Porta TCP aberta no servidor. `0` pede alocação automática (reaproveita a porta já alocada ao serviço de mesmo nome). |
| `domain` | texto | não | ausente | Domínio **legado** (um só). Prefira `domains`. |
| `tls` | verdadeiro/falso | não | `false` | TLS do `domain` legado. |
| `domains` | lista de rotas de domínio | não | vazio | Rotas de domínio: cada uma com `domain`, `port` e `tls`. |
| `env` | mapa texto → texto | não | vazio | Variáveis do serviço. Valor `secret:NOME` referencia um secret; `${CHAVE}` vem do arquivo de variáveis. |
| `env_comments` | lista de comentários | não | vazio | Comentários do editor `.env`, cada um ancorado a uma chave. |
| `volumes` | lista de textos | não | vazio | Cada item é `host:container` ou `host:container:ro`. **Item inválido é descartado em silêncio.** |
| `healthcheck` | objeto `healthcheck` | não | ausente | Healthcheck. Omitido, o serviço fica **sem** healthcheck (`none`). |
| `replicas` | inteiro | não | `1` | Número de containers. Padrão e mínimo `1` (`0` vira `1`). |
| `resources` | objeto `resources` | não | ausente | Limites de CPU e memória. |
| `command` | texto | não | ausente | Sobrescreve o comando da imagem. |
| `args` | lista de textos | não | vazio | Argumentos do comando. |
| `db` | texto | não | ausente | Tipo de banco: `postgres`, `mongodb`, `mariadb`, `mysql` ou `redis`. |
| `shared` | verdadeiro/falso | não | `false` | Marca o serviço como **servidor de banco compartilhado**. Os projetos autorizados ficam no daemon, não no manifesto. |

### `source` (use **uma** das chaves)

| Campo | Tipo | Obrigatório | Padrão | |
|---|---|---|---|---|
| `registry` | texto | não | ausente | Imagem de registry (`nginx:latest`). |
| `git` | objeto `git` | não | ausente | Repositório Git com Dockerfile. |
| `compose` | texto | não | ausente | O YAML de uma stack Compose, como texto. |
| `compose_ingress` | texto | não | ausente | Em stacks Compose, o serviço **dentro do YAML** que recebe o domínio. Sem ele o daemon descobre pela porta do domínio. |

### `source.git`

| Campo | Tipo | Obrigatório | Padrão | |
|---|---|---|---|---|
| `url` | texto | sim | — | Obrigatório. URL do repositório. |
| `branch` | texto | não | ausente | Padrão `main`. |
| `root_path` | texto | não | ausente | Gravado, mas o deploy ainda **não usa**. Padrão `.`. |
| `dockerfile` | texto | não | ausente | Caminho do Dockerfile, relativo ao contexto. Padrão `Dockerfile`. |
| `context` | texto | não | ausente | Pasta enviada como contexto de build. Padrão `.`. |
| `build_stage` | texto | não | ausente | Gravado, mas o deploy ainda **não usa**. |
| `submodules` | verdadeiro/falso | não | `false` | Gravado, mas o deploy ainda **não usa**. |
| `watch_paths` | lista de textos | não | vazio | Caminhos (relativos à raiz do repositório; aceita `*` e `**`) que um push precisa tocar para o **webhook** disparar o deploy. Vazio: todo push da branch dispara. Ver [Webhooks](/guias/webhooks/#filtro-por-caminhos-watch_paths). |
| `username` | texto | não | ausente | Usuário do clone, se o provedor exigir. |
| `credentials` | texto | não | ausente | O **nome** de um secret do projeto com o token de clone. |
| `provider` | texto | não | ausente | O **nome** de uma conta Git conectada. Se não existir no destino (nem no arquivo de variáveis), a importação **aborta**. |

### `healthcheck`

| Campo | Tipo | Obrigatório | Padrão | |
|---|---|---|---|---|
| `type` | texto | não | `tcp` | `none`, `tcp`, `http` ou `docker` (maiúsculas valem). **Omitido, vale `tcp`**, e qualquer valor desconhecido também vira `tcp`. |
| `path` | texto | não | ausente | Só para `http`. Padrão `/`. |
| `status` | inteiro | não | ausente | Só para `http`. Status esperado, padrão `200`. |
| `interval` | inteiro | não | ausente | Segundos entre tentativas. Padrão `5`. |
| `timeout` | inteiro | não | ausente | Segundos por tentativa. Padrão `3`. |
| `retries` | inteiro | não | ausente | Tentativas. Padrão `10`. |
| `start_period` | inteiro | não | ausente | Segundos antes da primeira tentativa. Padrão `5`. |

### `resources`

| Campo | Tipo | Obrigatório | Padrão | |
|---|---|---|---|---|
| `cpu_shares` | inteiro | não | `0` | Peso de CPU. `0` = sem limite. |
| `mem` | texto | não | ausente | Limite de memória: `1024`, `256k`, `256m` ou `2g`. |

### Item de `domains`

| Campo | Tipo | Obrigatório | Padrão | |
|---|---|---|---|---|
| `domain` | texto | sim | — | Obrigatório. O nome do domínio. |
| `port` | inteiro | não | ausente | Porta do container para este domínio. Omitida, vale a `port` do serviço. |
| `tls` | verdadeiro/falso | não | `false` | HTTPS automático (ACME). |

### Item de `env_comments`

| Campo | Tipo | Obrigatório | Padrão | |
|---|---|---|---|---|
| `text` | texto | sim | — | A linha completa, incluindo o `#`. |
| `before_key` | texto | não | ausente | A chave que vem logo depois do comentário. Omitida, é um comentário solto, no fim. |


## Valores de variáveis: `secret:NOME`

Um valor de `env` é um texto comum ou `secret:NOME`, a referência a um **secret do projeto** (o valor
não vai no arquivo). Ao exportar **sem valores**, os valores comuns saem redigidos. Veja
[Como as variáveis são resolvidas](/conceitos/variaveis-de-ambiente/).

## Comportamentos que surpreendem

| Você escreve | O que acontece |
|---|---|
| um campo com **erro de digitação** (`replica: 5`) | é **ignorado em silêncio**: o parser não rejeita campos desconhecidos |
| duas chaves em `source` (`registry` e `git`) | vale a **primeira** na ordem `registry`, `git`, `compose`; sem erro |
| `port` ausente | vale `0`, sem erro |
| `healthcheck: { path: /saude }` sem `type` | vale `tcp`; o `path` é ignorado |
| um volume sem `:` ou com lado vazio | é **descartado** |
| `replicas: 0` | vira `1` |
