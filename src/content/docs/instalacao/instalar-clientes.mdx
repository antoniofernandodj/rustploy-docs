Os clientes são intercambiáveis: falam com a mesma API e entram com o mesmo
[token de conexão](/instalacao/primeiro-acesso/).

## Web UI: zero instalação

O daemon já serve a interface na porta da API. Abra no navegador:

```text
http://SEU_SERVIDOR:9797
```

(ou `https://` se você configurou `[api].domain`). Cole o token de conexão. A
web UI é um PWA: o navegador oferece instalá-la como aplicativo.

## GUI desktop

Um aplicativo nativo, leve, com bandeja do sistema e notificação quando um
deploy termina. Ele **não precisa estar na mesma máquina do daemon**.

### Linux (um comando)

Em Debian, Ubuntu ou derivados (amd64):

```bash
curl -fsSL https://raw.githubusercontent.com/antoniofernandodj/rustploy/main/install.sh | sudo sh -s -- gui
```

Baixa o `.deb` da última release, confere o SHA-256 e a assinatura minisign e instala com `apt`. Depois abra **Rustploy** no menu de
aplicativos ou rode `rustploy-gui`.

### Windows (um comando)

No PowerShell, sem administrador:

```powershell
irm https://raw.githubusercontent.com/antoniofernandodj/rustploy/main/install.ps1 | iex
```

Baixa o zip portátil da última release, confere o SHA-256 e a assinatura minisign (recusa o zip se não bater com
uma chave do Rustploy; para conferir, baixa o `minisign.exe` oficial e confere o SHA-256 dele), instala em
`%LOCALAPPDATA%\Rustploy` e cria o atalho no Menu Iniciar. As opções e o que fazer se ainda não houver release estão em
[Instalação rápida](/instalacao/instalacao-rapida/).

### Pelo crates.io (Linux, Windows, macOS)

Com a toolchain Rust instalada, o jeito mais curto:

```bash
cargo install rustploy-gui
rustploy-gui
```

### Linux (.deb, gerando o pacote)

Gere o pacote a partir do repositório e instale:

```bash
make deb-gui          # gera dist/*.deb
sudo dpkg -i dist/rustploy-gui_*.deb
```

Depois abra **Rustploy** no menu de aplicativos ou rode `rustploy-gui`.

### Windows (zip portátil, gerando o pacote)

O repositório gera um `.zip` portátil com `make rustploy-gui-windows-dist`
(resultado em `dist/rustploy-gui-windows.zip`). Descompacte e execute o
`rustploy-gui.exe`.

<Aside type="note">
  O executável do Windows ainda não tem uma assinatura que o SmartScreen
  reconheça de imediato. Se aparecer o aviso, use "Mais informações → Executar
  assim mesmo".
</Aside>

## Qual usar?

| | Web UI | GUI desktop |
|---|---|---|
| Instalação | nenhuma | pacote |
| Notificações do sistema | não | sim, mesmo com a janela fechada |
| Vários servidores salvos | não | sim |
| Funciona em celular | sim (PWA) | não |

As duas cobrem o dia a dia. Alguns recursos só existem pela API ou pelo MCP.
