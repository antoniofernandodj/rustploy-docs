Rustploy ships **386 application templates**. Each page shows the containers, images, port, generated variables and the full compose file. To use one, see [One-click templates](/en/guias/templates/).

## Value generators

In template variables, these markers turn into values when the service is created:

| Marker | Result |
|---|---|
| `${domain}` | a provisional domain (`app-xxxx.example.com`) that you replace with yours |
| `${password:N}` | random password of N characters |
| `${base64:N}` | random base64 key |
| `${hash:N}` | random hash |
| `${uuid}` | random UUID |
| `${email}` / `${username}` | generated email and username |
| `${jwt}` | generated JWT |
