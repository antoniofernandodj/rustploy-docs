**Monitoring** (side menu) shows the **usage right now**, of the server and of each container.

## The four indicators

| Indicator | Shows |
|---|---|
| **CPU** | the server's total CPU use |
| **MEMORY** | memory in use out of the total (`447 MB / 3.8 GB`) |
| **DISK** | disk used out of the total, of the **largest mount point** (`9.2 GB / 49.0 GB`) |
| **LOAD** | the system load average over 1, 5 and 15 minutes (`0.00 0.00 0.00`) |

## The container table

One row per running service container, with **CONTAINER**, **PROJETO**, **CPU**, **MEM**, **RX** and **TX** (network received and
sent). The container name opens its **service** and the project opens the **project** (both are links). With nothing running, the screen says *"Nenhuma métrica ainda — aguardando o primeiro container em execução."* (No metrics
yet, waiting for the first running container.) The per-container numbers only appear from the first collection cycle after the
container starts.

<Aside type="note" title="Only the present">
  The screen shows the current value, refreshed every 2 seconds. **There is no chart or history.** For that, use an external tool,
  such as Beszel or Uptime Kuma from the [template catalog](/en/templates/).
</Aside>
