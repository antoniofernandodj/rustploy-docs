Rustploy competes with larger, older self-hosted deployment platforms. This page compares the four
with facts you can check, and says **when each one is the best choice**, including when it is not Rustploy.

<Aside type="note" title="How to read this comparison">
  The data on Dokploy, Coolify and CapRover comes from their official documentation and repositories,
  **checked on 2026-10-15** (links at the end). These projects change fast: check the source before you
  decide. **"Not stated"** means the pages consulted do not say, not that the feature does not exist.
</Aside>

## In one sentence

| | |
|---|---|
| **Rustploy** | one machine, one binary, built-in proxy and HTTPS, no Swarm or Traefik, with a native MCP server |
| **Dokploy** | an open source alternative to Heroku, Vercel and Netlify, with multi-server and Docker Swarm clustering |
| **Coolify** | a dashboard that controls one or more servers over SSH, with more than 280 one-click services |
| **CapRover** | a PaaS on Docker Swarm and nginx, with a CLI and web UI, and no lock-in: remove CapRover and the apps keep running |

## Where Rustploy is better (per the sources consulted)

- **Operational simplicity on one machine.** No Swarm, no Traefik, no separate panel: the daemon, proxy, database (SQLite) and registry are a single process.
- **Native MCP.** The daemon serves an MCP server: an agent such as Claude Code deploys and waits for the result, reads build logs and diagnoses a 502. See [Operate with AI agents](/en/agentes/visao-geral/).
- **Shared database with migration.** One Postgres, MySQL, MariaDB or MongoDB server for several projects, with a database and user per project, and a migration wizard with rollback.
- **Pre-deploy.** Jobs that run before a deploy and block it if they fail (migrations, tests).
- **Embedded OCI registry.**

## Where Rustploy is worse

- **One server only.** No cluster or multi-server. If you need more than one machine, pick another.
- **No data backups**, no Slack, Discord or email notifications, no metrics history and no CLI.
- **Dockerfile only.** No buildpacks.
- **No access control.** A single administrator token, with no users or scopes.
- **A new, small project.** Community, third-party documentation and production track record are much smaller. Some features have known gaps, listed in the documentation.

## When to pick each

| If you... | Pick |
|---|---|
| have **one VPS**, use Docker, want the fewest moving parts, and want to operate through an AI agent | **Rustploy** |
| need **several servers**, automatic database backups and notifications | **Dokploy** or **Coolify** |
| want the **largest catalog** of one-click services and pull request previews | **Coolify** |
| already use **Docker Swarm** and prefer a CLI and nginx | **CapRover** |
| want a **hosted option** next to self-hosted | **Dokploy Cloud** or **Coolify Cloud** |
