The [MCP](/en/agentes/visao-geral/) gives the agent **access** to the server. The
`rustploy-app` skill tells it **how to use that access well**: which stack to use,
where each password lives, how to create the database and the initial user, when to
ask for a subdomain and how to check that the app is really online. It was written
for people who ask the agent for apps without being developers. The skill itself is
written in Portuguese.

## What the skill makes the agent do

- **Fixed stack**: Rust + Axum + SQLx backend (routes → services → repositories layers),
  Vue 3 + Vite frontend served by nginx, Postgres.
- **No secrets in the repository**: everything through environment variables; passwords
  and keys in [secrets](/en/guias/variaveis-e-secrets/), **generated by Rustploy itself**
  ([`SecretGenerate`](/en/agentes/receitas/#generate-a-password-without-the-agent-seeing-it)),
  never passing through the agent. A person reads a password when needed (the first login)
  through the 👁 on the Secrets screen. A check runs before every commit.
- **Platform database**: a dedicated database on the [shared server](/en/guias/banco-compartilhado/).
- **Migrations and initial user** in a [pre-deploy](/en/guias/pre-deploy/) [job](/en/guias/jobs/),
  with an idempotent seed (email and password from the environment).
- **Frontend and backend on the same origin**: the frontend's nginx forwards `/api/` to the
  backend over the [project network](/en/conceitos/rede-e-nomes/); only the frontend has a domain.
- **Subdomain and HTTPS**: tells the person which DNS record to create, waits for it to
  propagate and adds the [TLS domain](/en/guias/dominios-e-tls/).
- **Asks before destroying anything** and only calls the app done after testing the public URL.

It also ships tested templates (backend and frontend) and a map of common mistakes.

## Install

<Steps>
1. In Claude Code, add the marketplace and install the plugin:

   ```text
   /plugin marketplace add antoniofernandodj/rustploy-skills
   /plugin install rustploy-apps@rustploy-skills
   ```

   From the terminal:

   ```bash
   claude plugin marketplace add antoniofernandodj/rustploy-skills
   claude plugin install rustploy-apps@rustploy-skills
   ```

2. Connect Claude Code to your server's MCP if you have not yet: see
   [Connect Claude Code](/en/agentes/conectar-claude-code/).
3. Restart Claude Code.
</Steps>

Then just ask in plain language. The skill kicks in when the request is to create,
ship or change an app. To call it explicitly: `/rustploy-apps:rustploy-app`.

<Aside type="caution" title="The MCP token is an administrator token">
  It only goes into the `claude mcp add` command, in the terminal. Never into a repository
  file, a committed `.mcp.json` or the chat. See [Security](/en/agentes/seguranca/).
</Aside>

## Update

The skill evolves over time. To get the newest version:

```text
/plugin marketplace update rustploy-skills
```

Or turn on auto-update in `/plugin` → **Marketplaces** → `rustploy-skills`.
