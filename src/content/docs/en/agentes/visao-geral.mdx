`rustployd` embeds an **MCP** (Model Context Protocol) server. Any agent that speaks MCP, such as Claude Code,
operates your server by conversation, from **any machine**. The desktop app does not need to be open.

## What the agent can do

- List projects and services, with status and port.
- **Trigger a deploy and wait for the result**, getting `ok`, the cause of the error and the end of the log.
- Read the build log, paginated.
- Diagnose a **502** by looking at the proxy's live route table, and fix it without a redeploy.
- Run **any** protocol command, through the `rpc` tool: create a service, change variables, export the manifest, run a job.

## How it works

MCP is just JSON-RPC 2.0 on a `POST /mcp` (*Streamable HTTP* transport, JSON responses, no SSE). The tools call
the same code the screens use; there is no back door exclusive to humans or to AI.
